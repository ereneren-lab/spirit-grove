디자인 작업(BX·그래픽·UX/UI·영상)은 **자동 위임**으로 진행한다.
사용자는 목표만 말하고, Orchestrator(메인 세션)가 결과물 유형을 판별해
design-researcher → design-strategist → creative-producer 순으로 알아서 넘긴다.
`@design-researcher ...` 같은 직접 호출은 사용자가 명시적으로 그렇게 부를 때만 쓴다.

**Why:** 2026-08-04에 세 가지 사용법(자동 위임 / 직접 호출 / 전체 워크플로)을 제시했더니
사용자가 "자동 위임으로 가자"를 골랐다. 즉 **단계마다 어떤 에이전트를 부를지 사용자가 지시하길 원치 않는다.**

**How to apply:** 디자인 요청을 받으면 먼저 프로젝트 브리프(프로젝트명·배경·목표·타깃·결과물 유형·
요구사항·제약·참고 경로·저장 경로·완료 기준)를 만들고, 그걸 서브에이전트에 통째로 넘긴다.
CLAUDE.md의 「에이전트 전달 원칙」대로 **서브에이전트는 이전 대화를 모른다고 가정**한다.
병렬 가능(시장/경쟁사 조사, 복수 콘셉트)과 순차 필수(리서치→전략→제작→검수)를 구분한다.
⚠️ 다만 CLAUDE.md는 "핵심 전략을 임의로 확정하지 않는다"고도 정한다 — **단계 사이 검토는 받되,
사소한 것은 가정을 표시하고 진행**한다(작업을 멈추는 질문은 피한다). [[spirit-grove-path]] 참고:
에이전트는 새 경로에서 세션을 열어야 로드된다.
