정령의 숲(`~/Desktop/spirit-grove`)은 진행상황을 저장소 루트의 `WORKLOG.md`에 기록한다.
역할 분담: `CLAUDE.md` = 영구 지식(아키텍처·규칙·함정), `WORKLOG.md` = 휘발성 상태(현재 커밋·진행 중인 작업·다음 할 일).

**Why:** 2026-07-20에 세션 컨텍스트가 날아가 "하던 게 어디 갔냐"는 상황이 실제로 발생했다.
작업물 자체는 커밋돼 무사했지만, 어디까지 했고 뭘 하려던 참인지가 대화에만 있어서 복구에 시간이 들었다.
사용자가 명시적으로 "작업이 끊기면 곤란하니 요약 문서 + 메모리 한 줄을 계속 업데이트하자"고 요청했다.

**How to apply:** 세션 시작 시 CLAUDE.md 다음으로 `WORKLOG.md`를 읽는다.
커밋할 때마다 「현재 상태」(최신 커밋·빌드 상태)를 고치고 「세션 기록」 맨 위에 블록을 추가한다.
작업이 미완인 채 끊길 것 같으면 그 상태 그대로 「진행 중인 작업」에 적어둔다.
