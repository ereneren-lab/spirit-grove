정령의 숲(spirit-grove) 프로젝트의 오케스트레이터(브리프)가 design-strategist에게 명시적으로 요구한 규칙: "근거 없는 수치를 지어내지 마라. 센 것은 실제로 grep해서 세어라."

2026-08-04 중간 서사 전략 작업에서 이 원칙을 지킨 방식:
- `playStory(...)` 호출부를 실제로 grep해 정확히 7곳(배열 7개)임을 확인하고, 그중 가이드 경로(목표 트래커)에 포함되는 게 3개뿐이라는 걸 코드 흐름(`currentGoal()`, `trainerDefeated()`, `move()` 내 타일 트리거)을 직접 읽어서 입증했다.
- 반대로 라이벌 카이 4연전(V/V2/V3/V4)이 실제로 guaranteed 인카운터인지는 맵 문자열을 직접 파싱하지 않고는 확정할 수 없어서, 근거 없이 "guaranteed"라고 단정하지 않고 "전제·미확정 사항"으로 따로 분리해 명시했다(NPC가 `dir`/`range` 시야 감지 속성이 없어 t1~t21과 다른 상호작용 방식이라는 근거까지 남김).

**Why**: 이 저장소는 밸런스·도달성 관련 버그가 "정의는 있는데 실제 플레이에 닿지 않는다"는 패턴으로 반복 발생했던 이력이 있다(`docs/SPIRIT_GROVE_GUIDE.md`의 "죽은 콘텐츠 감사" 섹션). 전략 문서도 같은 함정(존재는 하지만 도달 안 되는 콘텐츠를 "있다"고 서술)에 빠지기 쉽다.

**How to apply**: 이 저장소에서 서사/콘텐츠 배치 전략을 짤 때는 (1) 데이터/텍스트가 "정의돼 있다"는 것과 "플레이어가 실제로 도달한다"는 것을 분리해서 판단하고, (2) 도달성을 코드로 확정 못 한 항목은 전략의 핵심 근거로 쓰지 말고 "확인 필요"로 격리할 것. 우선순위를 매길 때도 "확실히 guaranteed한 지점"에 붙는 비트를 "아마 guaranteed일 것 같은 지점"보다 우선한다.
