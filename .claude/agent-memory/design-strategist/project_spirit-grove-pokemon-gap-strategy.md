2026-08-05, `outputs/research/2026-08-05_spirit-grove_pokemon-gap-research.md`(포켓몬과의 갭 6개 순위)를
`outputs/strategy/2026-08-05_spirit-grove_pokemon-gap-strategy.md`로 전략화했다.

**핵심 입장**: "새 시스템 추가"보다 "이미 있는 것을 닿게 하고 깊게 쓰기"가 이 프로젝트에 더 값어치
있다. 근거: 이 저장소는 "정의는 있는데 플레이에서 안 닿는다" 버그를 반복 생산해왔고(특수조우 11곳·
learn 배열 8종·못 얻는 TM·2026-08-05 트래커 캐시버그로 결말 2종 증발, [[project-spirit-grove-narrative]]
참조), 리서치 1순위(spa/spDef 성격 부재) 자체도 "새 시스템"이 아니라 **이미 존재하는 물리/특수 분리
시스템(SPEC_TYPES, 타입 10개를 물리5:특수5로 정확히 이등분 — `tables.js` L9-19)을 성격 시스템이
절반만 따라간 배선 누락**이었다.

**코드 판독으로 리서치 판단을 정정한 지점**(중요 — 다음에 성격/밸런스 관련 작업 시 참조):
- 리서치는 "spa/spDef 성격 추가는 위험 없음, 1시간"이라고 했으나, `makeMon`(`dex.js` L107)은
  야생·트레이너·알 생성이 전부 공유하고 트레이너 팀 생성(`index.html` L5063 `t.mons[i]=makeMon(...)`)도
  같은 함수를 쓴다. 즉 신규 성격은 "플레이어 전용 추가=밸런스 불변"이 아니라 **트레이너 로스터의
  무작위 생성 풀에도 섞인다** — 소폭이지만 `balance_test.js`·`league_test.js` 재측정이 필요한 카테고리.
- 이미 `mint_*` 아이템 5종(선두 정령 성격 확정 지정, `index.html` L5855-5859·L6186-6190)이 존재해
  성격을 "닿게" 만드는 UX 인프라가 있다 — 새 성격만 추가하면 이 인프라 밖에 남으므로, 실제 구현
  범위는 "테이블 추가"보다 크다(대응 mint 5종 필요).
- `scripts/dead_content_test.js`가 이미 "정의는 있는데 안 닿는다" 패턴을 자동 감사하지만 범위는
  아이템 획득경로·이름표·트레이너 배치·문자열 노출뿐 — 성격↔민트 매칭, 트래커 라우팅(오늘 버그
  유형)은 이 감사의 사각지대. 전략에서 이 감사 범위를 확장하는 걸 별도 실행 묶음(B)으로 제안했다.

**하지 말 것으로 명시한 것**: 타입 8개 확대(아트 병목, 별개 6개월+ 프로젝트 — 리서치가 1~6순위
표에 같이 나열해 시간축이 다른 일을 섞어놓은 걸 바로잡음), 성격 25종 풀 그리드(5개로 물리:특수
나침반은 완성됨), 진화 조건 다양화(라인 이미 86% 커버, 재측정 따르는 새 콘텐츠 범주라 보류),
트레이너 팀 깊이(갭 여부 자체가 미확인).

**How to apply**: 다음에 이 프로젝트에서 밸런스/성격/아이템 관련 작업을 할 때 이 전략 문서를 먼저
확인할 것. 특히 "플레이어 전용 추가 = 밸런스 불변"이라는 이 프로젝트의 기존 통념은 `makeMon`을
공유하는 항목(성격·IV/EV 등)에는 적용되지 않을 수 있다는 걸 기억할 것 — 매번 실제로 어느 함수가
그 데이터를 소비하는지 grep해서 확인하고, "플레이어 전용"이라는 주장이 나오면 트레이너 생성 경로와
공유되는지부터 반증 시도할 것. [[feedback-spirit-grove-evidence-grounding]] 참조.
