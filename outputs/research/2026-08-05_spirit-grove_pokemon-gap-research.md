## 3. 최종 갭 순위 (7개 → 6개, 1순위 변경)

### 🔴 **1순위. 특수 스탯 성격 보정 부재** ← **새로 발견**

**발견**:
성격 10개 모두 구현되나, **특수공격·특수방어 보정이 완전히 없음**.

**실측** (`src/rules/tables.js` 라인 33-39):
```javascript
const NATURES=[
  {up:null,down:null},               // 노력하는
  {up:"atk",down:"def"},             // 외로운 — atk만
  {up:"atk",down:"spd"},             // 용감한 — atk만
  {up:"def",down:"atk"},             // 대담한 — def만
  {up:"def",down:"spd"},             // 무사태평 — def만
  {up:"spd",down:"atk"},             // 겁쟁이 — spd만
  {up:"spd",down:"def"},             // 성급한 — spd만
  {up:"atk",down:"def"},             // 고집있는 — atk만
  {up:"spd",down:"atk"},             // 명랑한 — spd만
];
```
**spa(특수공격), spDef(특수방어)는 단 하나도 없다.**

**포켓몬의 25개 성격**:
- 5×5 행렬 = atk·def·spa·spd·spDef 모두에 보정

**손실**:
- 특수기술 중심 정령들(파라온 불 특공, 화염나방 불 특공, 루나비 비행 특공) **성격으로 특공을 올릴 수 없음**
- 팀 빌딩에서 "특수 어태커용 성격 선택"이 없음
- 같은 종을 여러 마리 키울 이유 감소

**구현**:
- 🟢 매우 낮음 (1시간)
- spa/spDef 보정 성격 5개 추가
- 메커닉 이미 구현 (recalc 라인 123)

**액션**: ✅ **즉시 가능**
